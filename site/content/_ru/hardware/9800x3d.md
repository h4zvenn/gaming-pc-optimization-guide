**Цель:** оптимизация производительности процессора с помощью BIOS с обязательной проверкой стабильности.

> **Важно:** разгон не гарантирует прирост FPS и может вызвать нестабильность, повышение температуры и ускоренный износ оборудования. Все изменения выполняются на свой риск.

## 1. Характеристики процессора

| Параметр | Значение |
|---|---|
| Процессор | AMD Ryzen 7 9800X3D |
| Архитектура | Zen 5 |
| Ядра / потоки | 8 / 16 |
| Базовая частота | 4,7 ГГц |
| Максимальная штатная Boost-частота | До 5,2 ГГц |
| TDP | 120 Вт |
| Максимальная температура (Tjmax) | 95°C |

## 2. Подготовка

Перед изменением настроек:

1. Обновите BIOS до подходящей стабильной версии по инструкции производителя материнской платы.
2. Проверьте охлаждение и температуру процессора.
3. Сохраните текущие настройки BIOS.
4. Запишите результаты тестов до оптимизации.

Не рекомендуется одновременно изменять PBO, Curve Optimizer и параметры памяти.

## 3. Настройка BIOS

Перезагрузите компьютер и войдите в BIOS с помощью `Del` или `F2` (зависит от материнской платы).

Названия меню могут различаться на ASUS, MSI, Gigabyte и других платах.

### Начальные настройки

| Параметр | Рекомендация |
|---|---|
| AMD EXPO | Включить при наличии совместимой памяти |
| Precision Boost Overdrive | Advanced |
| PBO Limits | Auto, первоначально |
| PBO Scalar | Auto / 1X |
| CPU Boost Clock Override | 0 MHz, первоначально |
| Curve Optimizer | Disabled, первоначально |

Сначала проверьте производительность и стабильность базовой конфигурации.

### Дополнительная настройка Boost

При достаточном охлаждении можно постепенно проверить:

- CPU Boost Clock Override: +50 MHz.
- Затем +100 MHz, если предыдущий вариант стабилен.
- Более высокие значения — только после дополнительных проверок.
- PBO Limits: Motherboard — необязательный эксперимент, способный увеличить энергопотребление и нагрев.

Параметр Boost Override изменяет верхний предел частоты, но не гарантирует постоянный Boost.

Не рекомендуется использовать PBO Scalar 7X–10X как универсальную настройку.

## 4. Curve Optimizer

Curve Optimizer позволяет смещать кривую напряжения и частоты процессора.

Для осторожного начала:

1. Откройте Precision Boost Overdrive → Curve Optimizer.
2. Выберите All Cores.
3. Установите Negative.
4. Начните с -5.
5. Проверьте стабильность.
6. При стабильной работе можно протестировать -10.

Оптимальные значения индивидуальны. Отрицательный Curve Optimizer не гарантирует стабильность или снижение температуры во всех нагрузках.

При появлении ошибок уменьшите величину отрицательного смещения или верните стандартные настройки.

## 5. Проверка стабильности

Используйте:

- **HWiNFO64** — мониторинг температуры, частот и энергопотребления.
- **OCCT** — тестирование стабильности процессора.
- **Cinebench 2024** — сравнение результатов до и после настройки.
- **Игровые тесты** — проверка FPS, 1% Low и времени кадра.

Начните с коротких тестов, затем проведите более длительные проверки, включая игры и малопоточные нагрузки.

15–30 минут тестирования не гарантируют полной стабильности.

Обращайте внимание на:

- Вылеты приложений и перезагрузки.
- Ошибки WHEA.
- Снижение производительности.
- Необычно высокие температуры и троттлинг.

Максимальная рабочая температура Ryzen 7 9800X3D по спецификации AMD — 95°C. Это предел, а не целевая температура для разгона.
