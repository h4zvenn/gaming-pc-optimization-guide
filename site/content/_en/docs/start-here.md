## Before you change anything

Keep a record of the original setting. If a change makes the game worse, undo it before trying another. You do not need to apply every recommendation in this guide.

Do not disable security features or anti-cheat protection to chase FPS. Read [mistakes to avoid](11-what-not-to-do.html) before using a tweak or tool you do not understand.
