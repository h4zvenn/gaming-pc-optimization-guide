**Goal:** Improve CPU performance through controlled BIOS tuning while prioritizing stability and measurable results.

> **Warning:** Overclocking does not guarantee higher FPS. It may cause instability, increased temperatures, and accelerated hardware wear. Proceed at your own risk.

## 1. CPU Specifications

| Specification | Value |
|---|---|
| Processor | AMD Ryzen 7 9800X3D |
| Architecture | Zen 5 |
| Cores / Threads | 8 / 16 |
| Base Clock | 4.7 GHz |
| Maximum Stock Boost | Up to 5.2 GHz |
| TDP | 120 W |
| Maximum Operating Temperature (Tjmax) | 95°C |

## 2. Preparation

Before changing BIOS settings:

1. Update your BIOS to an appropriate stable version following your motherboard manufacturer's instructions.
2. Verify CPU cooling and temperatures.
3. Save your current BIOS configuration.
4. Record baseline benchmark results.

Avoid changing PBO, Curve Optimizer, and memory settings simultaneously.

## 3. BIOS Configuration

Restart your PC and enter BIOS using `Del` or `F2`, depending on your motherboard.

Menu names may differ between ASUS, MSI, Gigabyte, and other manufacturers.

### Initial Settings

| Setting | Recommendation |
|---|---|
| AMD EXPO | Enable if compatible memory is installed |
| Precision Boost Overdrive | Advanced |
| PBO Limits | Auto initially |
| PBO Scalar | Auto / 1X |
| CPU Boost Clock Override | 0 MHz initially |
| Curve Optimizer | Disabled initially |

Test performance and stability before making further adjustments.

### Optional Boost Clock Tuning

With adequate cooling, gradually test:

- CPU Boost Clock Override: +50 MHz.
- Increase to +100 MHz if stable.
- Test higher values only after additional validation.
- PBO Limits: Motherboard is optional and may increase power consumption and temperatures.

Boost Clock Override raises the permitted frequency ceiling. It does not guarantee sustained boost clocks.

Avoid treating PBO Scalar 7X–10X as a universal recommendation.

## 4. Curve Optimizer

Curve Optimizer adjusts the CPU voltage-frequency curve.

A conservative starting approach:

1. Open Precision Boost Overdrive → Curve Optimizer.
2. Select All Cores.
3. Choose Negative.
4. Start with -5.
5. Test stability.
6. If stable, consider testing -10.

Optimal values vary between processors. A negative Curve Optimizer setting does not guarantee lower temperatures or stability under every workload.

If instability occurs, reduce the negative offset or restore default settings.

## 5. Stability Testing

Recommended tools:

- **HWiNFO64** — monitor CPU temperatures, frequencies, and power consumption.
- **OCCT** — CPU stability testing.
- **Cinebench 2024** — compare performance before and after tuning.
- **Game benchmarks** — compare average FPS, 1% Low FPS, and frame times.

Start with short tests, then perform longer validation, including gaming and lightly threaded workloads.

A 15–30-minute test cannot guarantee complete stability.

Watch for:

- Application crashes or unexpected restarts.
- WHEA hardware errors.
- Performance regressions.
- Excessive temperatures and thermal throttling.

AMD specifies a maximum operating temperature of 95°C for the Ryzen 7 9800X3D. This is an operating limit, not an overclocking temperature target.
