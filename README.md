## Why this project exists

PC optimization is full of conflicting advice. A tweak that helps one setup can do nothing — or make things worse — on another.

This project is built around a simpler idea: **make informed changes and let the results decide.**

### Our workflow

The process is simple: **Measure → Diagnose → Change → Compare → Keep or revert.**

- **Evidence over hype.** Compare results instead of trusting "free FPS" claims.
- **One change at a time.** Know what actually affected performance.
- **Stability matters.** FPS alone does not tell the whole story.
- **Stay in control.** Understand how to undo a change before applying it.

> [!NOTE]
> There is no universal best configuration. Hardware, drivers, games, and personal priorities all affect the outcome.

Back up important data and create a restore point before changing system settings. Avoid scripts or tweaks you do not understand. Any changes are made at your own risk.
